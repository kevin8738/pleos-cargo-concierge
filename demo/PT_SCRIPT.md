# VIP 조수석 — v1.1.2 3분 PT 대본

현재 시연 기준은 **v1.1.2-pleos / versionCode 5**입니다. [전체 동선 무음 영상](../docs/검증자료/AVD_v1.1.2/전체동선_무음.mp4)은 공식 Pleos Connect v2.1 AVD의 연속 녹화로, 81.274078초·2560×1440입니다. 아래 시각은 발표 배분이며 영상 타임코드가 아닙니다. 무음 영상을 먼저 보여 주거나 장면에서 멈추고 설명합니다.

## 시연 조건

Vehicle SDK 2.3.2 / VehicleService 2.3.22(versionCode 74) / crp_avd_arm64 API 34에서 공식 Console 브라우저 heartbeat를 유지합니다. 시작 상태는 P·정차, SDK로 비착좌 확인, SYNC OFF, 조수석 설정 22℃입니다. 앱 안의 케이크 시나리오 버튼이나 데모 주입값은 실제 설정 변경의 허용 근거가 아닙니다.

현재 영상은 한 번의 케이크 선택 → 18℃ 설정값 확인 → 주행 배지 → P 및 운전석 문 열림 → 도착·22℃ 복원 → 전원 OFF 안내 → 착좌 미확인 보류까지 이어집니다. Console에서 넣은 주행 신호는 합성 입력입니다. 불연속 전환으로 리포트에 나타난 최대 **4.53G는 실차 수치나 G 추정 정확도 근거가 아닙니다.** 실제 코칭 음향도 이 무음 영상으로 확인하지 않습니다.

## 리허설 확인

- 현재 APK와 [AVD 재현 조건](../docs/검증자료/AVD_v1.1.2/README.md), [A1–A5 화면](../docs/README.md)을 사용합니다. 과거 v1.0.0 시연 영상과 v1.1.0 R 화면은 현재 구현의 증거로 소개하지 않습니다.
- 전체 동선 영상은 무음입니다. 발표자가 기능을 설명하되 영상에서 실제 음성이 재생됐다고 말하지 않습니다. 앱의 `TTS:` 로그도 재생 성공의 증거가 아닙니다.
- 시연 중 외부 변경·SYNC ON·주행 상태로 복원이 보류되면 상태 문구를 설명합니다. P 정차와 SYNC OFF를 확인한 뒤 화면의 명시적 재시도를 사용합니다. 재시작 후 원값을 자동 복원하는 기능은 없습니다.
- [조건별 10개 판정과 로그](../docs/검증자료/AVD_v1.1.2/results.json)는 전체 동선 영상과 별도 시험 결과입니다. 영상을 모든 오류 조건의 반복 시험으로 소개하지 않습니다.
- 앱의 “케이크 시나리오” 버튼과 `scenario_3min.sh`는 합성 화면·코칭 재현용 보조 수단입니다. 실제 SDK 제어와 확인 근거는 위 AVD 기록을 따릅니다.

이전 `demo_script.py`·`compose_demo.py` 기반 영상은 v1.0.0 시연의 제작 이력입니다. 일부 음성을 후처리 합성한 당시 결과를 현재 음향 검증으로 재사용하지 않습니다.
