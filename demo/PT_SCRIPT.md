# VIP 조수석 — 3분 PT 대본

시연 기준은 **제출 APK**, SHA-256 `6a4a41ed2aa8f73fb0a7dd2b3bf499d3074a5d2ec9ecd21273763611097df287`입니다. [전체 동선 무음 영상](../docs/검증자료/제출_APK/flow-01/전체동선_무음.mp4)은 공식 Pleos Connect v2.1 AVD의 연속 녹화로, 78.689944초·2560×1440·52,174,992바이트이며 오디오 스트림은 0개입니다. 아래 시각은 발표 배분이며 영상 타임코드가 아닙니다. 무음 영상을 먼저 보여 주거나 장면에서 멈추고 설명합니다.

## 시연 조건

Vehicle SDK 2.3.2 / VehicleService 2.3.22(versionCode 74) / crp_avd_arm64 API 34에서 공식 Console heartbeat를 유지합니다. 제출 검증에서는 heartbeat API를 사용하고 브라우저 physics 쓰기를 동시에 실행하지 않았습니다. 시작 상태는 P·정차, SDK로 비착좌 확인, SYNC OFF, 조수석 설정 22℃입니다. 앱 안의 케이크 시나리오 버튼이나 데모 주입값은 실제 설정 변경의 허용 근거가 아닙니다.

시연 전 Android 설정 → 앱 → VIP 조수석에서 위치 ‘앱 사용 중에만 허용’과 알림 허용을 확인합니다. GPS 보조 입력에는 시스템 위치 ON이 필요합니다. 사용자 선택으로 시작한 보호 세션은 알림이 있는 포그라운드 서비스를 사용합니다. 다른 화면에서의 세션 관측 범위는 아래 별도 관측 APK의 근거로 구분합니다.

현재 영상은 한 번의 케이크 선택 → 18℃ 설정값 확인 → 주행 배지 → P 및 운전석 문 열림 → 도착·22℃ 복원 → 전원 OFF 안내 → 착좌 미확인 보류까지 이어집니다. Console에서 넣은 주행 신호는 합성 입력입니다. 리포트는 최대 추정 0.32G와 ‘모의 입력·실주행 평가 불가’를 표시합니다. 별도 관측 APK의 4.49G와 입력·실행 환경이 달라 정확도 개선으로 비교하지 않습니다. 0.6G 판정 보류는 검증 전 팀 정책(D)이며 물리적 상한이나 오류 검출 기준이 아닙니다. 합성 재생값은 실차 G 정확도·보호 효과의 근거가 아닙니다. 실제 코칭 음향도 이 무음 영상으로 확인하지 않습니다.

## 리허설 확인

- 제출 APK와 [AVD 재현 조건](../docs/검증자료/제출_APK/README.md), [A1–A5 화면](../docs/README.md)을 사용합니다. [PT 실행 범위표](../docs/PT_실행범위표.md)의 대상 APK와 관측 범위를 확인합니다.
- 전체 동선 영상은 무음입니다. [별도 관측 APK](../docs/별도관측.md)(SHA-256 `8971e207285f333c2c152f185e907ea1d38c01c04369473fc68c8f850f5e023c`)의 선택 안내·주행 WARN/OVER PCM/OFF 대조는 제출 APK의 음향 성공으로 합산하지 않습니다. ON 원 정리 실패·별도 복구, 통합 전체 false와 수집 진단 FAIL을 함께 설명합니다. 순정 내비 발화 귀속·경합·차량 스피커·운전자 부담은 미검증이며 `TTS:` 요청 로그만으로 재생을 판단하지 않습니다.
- 별도 관측 APK의 백그라운드 설명은 직접 관측 20.297990초의 보수적 주기 실행 20개·TBT 6개로 한정합니다. 전체 경로 요청부터 복귀까지의 37.790876초 로그와 분모를 섞지 않습니다.
- 도착 시 리포트 응답과 서비스 종료를 확인했으며 최종 Idle/P 정차는 후속 종료·확인 단계의 결과입니다. 도착 직후 바로 Idle이 됐다고 설명하지 않습니다.
- 시연 중 외부 변경·SYNC ON·주행 상태로 복원이 보류되면 상태 문구를 설명합니다. P 정차와 SYNC OFF를 확인한 뒤 화면의 명시적 재시도를 사용합니다. 재시작 후 원값을 자동 복원하는 기능은 없습니다.
- [조건별 10개 판정과 로그](../docs/검증자료/제출_APK/control-01/results.json)는 전체 동선 영상과 별도 시험 결과입니다. 영상을 모든 오류 조건의 반복 시험으로 소개하지 않습니다.
- 앱의 “케이크 시나리오” 버튼과 `scenario_3min.sh`는 합성 화면·코칭 재현용 보조 수단입니다. 실제 SDK 제어와 확인 근거는 위 AVD 기록을 따릅니다.
