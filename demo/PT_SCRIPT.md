# VIP 조수석 (Cargo Concierge) — 3분 PT 데모 스크립트

> 무대 구성: Pleos_Connect_v2.1 AVD(또는 AAOS 에뮬레이터) 화면을 미러링. 발표자 1명(말), 오퍼레이터 1명(adb/버튼).
> 차량 신호는 **앱 안의 "▶ 케이크 시나리오(70초)" 버튼** 하나로 재생되고(모든 에뮬레이터에서 동작), 같은 타임라인을 `demo/scenario_3min.sh`로도 쏠 수 있다. 음성 안내는 TTS, 경고는 짧은 효과음.

> 제출용 시연 영상의 내레이션·콜아웃 문구는 `demo/demo_script.py`(compose_demo.py 장면 스크립트)에 있고, 이 PT 멘트와 같은 논지·같은 숫자를 쓴다. 영상은 에뮬레이터 TTS 엔진 부재로 차량 음성을 후처리 합성했지만, PT 현장에서는 앱의 `TTS:` 로그 줄을 가리키거나 TTS 엔진이 있는 기기에서 실제 발화로 보여준다.

| 0:25 | **[시나리오 시작]** 조수석 도어 열림 → 닫힘. 10초 카운트다운과 함께 시트 등장: 1행 말하기 타일 + **이전에 쓴 VIP(도자기·강아지·꽃다발)**, 2행 보호 분류 9종 | "베이커리 앞에 섰습니다. 기어 P, 속도 0, 그리고 **조수석 문이 열렸다 닫히는 순간** — 차는 '무언가 실렸다'는 걸 압니다. 이 세 신호의 조합은 차 안에서만 얻을 수 있습니다. 10초 안에 고르지 않으면 조용히 사라집니다. 운전자를 귀찮게 하지 않도록요." |
| 0:40 | 오퍼레이터: "케이크 실었어" (음성 텍스트 훅 또는 타일 탭). 로드 화면: 오늘의 VIP 케이크 · 허용 0.15G · 캐빈 칩 — *조수석 18℃ 적용됨 / 풍량 3 적용됨 / 열선 유지* | "말로 해도 됩니다. '케이크 실었어.' 조수석 존만 18℃(설정 범위 하한 근처, 에뮬레이터 15~30℃), 열선은 끕니다. ‘쇼케이스’는 비유이고 냉장이 아니라는 문구를 카드에 둡니다. 적용 결과를 숨기지 않습니다 — 차량이 거부하거나 권한이 없으면 칩에 그대로 뜹니다. | 2:40 | 설정 화면 잠깐: 빈 좌석 열선 동의 토글, 연결 소스(Pleos Vehicle 2.3.2 / NaviHelper 3.0.5 / FusedLocation / TTS·STT) | "SDK는 Vehicle(도어·기어·조향·브레이크·시트·공조), NaviHelper(도착·TBT·주의구간), FusedLocation(속도 보정), TTS/STT를 씁니다. 기본은 **읽기 전용 가드**라 출시 리스크가 낮고, 공조·열선 제어는 사용자 동의 위에서만 확장합니다." |

## 리허설 체크리스트
- [ ] 앱을 포그라운드에 두고 시작 (데모 브리지는 replay가 없음)
- [ ] 설정 → 음성 코칭 ON, 경고음 ON. 에뮬레이터 볼륨 확인. TTS 엔진이 없으면 로그 패널의 `TTS:` 줄을 가리키며 진행
- [ ] Pleos AVD에서 실제 Vehicle 신호가 들어오면 우측 패널 `차량 신호 · Pleos Vehicle SDK 2.3.2 + demo bridge` 표기 확인
- [ ] 백업: `demo/scenario_3min.sh` (MODE=broadcast). 앱 내부 버튼이 1순위, adb가 2순위
- [ ] 질문 대비: "왜 가속도계가 아닌가?" → 차량 신호만으로 동작해야 모든 Pleos 차량에서 추가 하드웨어 없이 동작하고, 조향각 기반이라 **코너 진입 전에** 코칭할 수 있음
