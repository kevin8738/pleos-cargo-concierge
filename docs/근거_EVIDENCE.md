# VIP 조수석 — 수치 근거표 (Evidence Sheet)

작성 2026-10-26 · 구현 범위 대조 갱신 2026-10-29 · 대상: 앱·기획서·시안·영상에 쓰인 모든 숫자. 코드의 한계값은 `app/core/.../model/CargoPreset.kt`에 있고, 이 표의 유도식은 `core/physics/CargoPhysics.kt`와 `CargoLimitRationaleTest`가 그대로 계산해 고정합니다(값을 바꾸면 어느 근거가 깨지는지 테스트가 말해 줍니다).

**근거 등급**
- **A** 법규·표준·제조사 공식 자료·직접 실측
- **B** 동료심사 문헌·공공기관 지침(언론 보도를 거친 경우 표기)
- **C** 물리 유도(식과 입력값을 함께 적음)
- **D** 팀 가정 — 예정된 실측·플랫폼 확인 결과가 확보된 항목만 갱신. 일정 경과를 확인 완료로 취급하지 않음

**적용 범위.** A/B는 인용한 자료·측정 자체의 근거 등급이지 앱의 보호 효과에 대한 인증이 아닙니다. 분류별 한계 G는 문헌·단순 물리식을 참고해 선택한 초기 설계값이며 물건의 실측 파손·넘침 한계로 확정하지 않았습니다. 공조 설정값은 상자 내부·식품 온도가 아닙니다. 현재 제출 자료에 실제 케이크·포장·좌석 조건의 검증 결과가 포함되지 않아 파손 감소율이나 보관 시간 연장을 주장하지 않습니다.

**현재 구현과 계획의 구분(2026-10-29 보완).** v1.1.0 소스는 제어의 정차 조건 재검사·적용/복원 순서화, 결과에 따른 복원 상태 표시, 앱 비정상 종료 후 미완료 표식 안내를 보완했습니다. 미완료 표식은 자동 세션 복구나 자동 복원 완료를 뜻하지 않습니다. 열선 ON 요청은 기존 동의와 무관하게 검증 대기 상태로 차단하며 30/45분 타이머를 구현·입증한 것으로 쓰지 않습니다. 2초 수신 신선도·공통 8초 간격·주행 안내 합계 6회는 D등급 프로토타입 정책이며 시험 결과와 별개입니다. v1.1.0의 이번 코어 테스트 109건·Pleos release 빌드 통과, lint 오류 0건·경고 33건은 구현 검증이며 AVD·실차 상태와 별도입니다. 앱 모듈 NO-SOURCE는 실행된 테스트 수로 세지 않습니다. 공식 AVD 설치·실행에서 온도 원값 조회 실패 시 미적용, 공유 풍량·풍향 유지 표시를 확인했습니다. 실제 온도 개선·원복 성공의 실차 증거는 아닙니다. 지오펜스 등록·연결, Gleo 호출어, 리포트 영구 저장·공유, 차종 자동 선택·센서 융합·조향각 미제공 시 방위각 대체는 향후 항목입니다. 내비 제한속도 이벤트는 코칭 조건에 반영하지 않습니다.

**집계 범위.** 리포트의 횟수는 앱 정책이 허용한 주행 안내 요청 수이며 실제 스피커 재생 완료 횟수가 아닙니다. 음소거·TTS 가용성과 순정 내비의 실제 소리는 별도 관찰합니다.

**검증의 종류.** v1.0.0 릴리스 기록의 앱 단위 테스트 73건은 당시 로직 검증, 공식 AVD 실행은 해당 환경의 SDK 연동 확인입니다. 이 수치를 v1.1.0의 새 회귀 검사 통과 건수로 재사용하지 않습니다. 브라우저 시뮬레이션 36개 검사와 A/B 결과 일치는 기능·회귀 검증이며 실차 시험이나 실제 케이크 파손률의 증거가 아닙니다. 화면 시안 S1~S5는 목표 UX이고 S6는 v1.1.0 에뮬레이터 실행 화면이며 영상은 v1.0.0 당시 기록입니다. 새 버전의 실행 화면·테스트와 구별합니다.

### 1.3 자리(조수석·뒷좌석·트렁크)와 한계값

현재 모델은 같은 차체의 차속·조향으로 얻은 G를 자리와 무관하게 사용합니다. 이는 단순화된 설계이며 좌석별 실제 진동·수직 충격·회전 중심 차이가 없다는 뜻은 아닙니다. 자리는 공조·시트 요청 영역을 정합니다. 후석의 실제 열선·통풍·독립 온도 존은 차종 제공 범위에 따라 결과를 표시하고, 트렁크는 공조·시트 요청을 미지원으로 처리합니다. 이미 사람이 앉은 자리는 열선·통풍 요청을 제외합니다. 에뮬레이터의 좌석 속성은 10/26 `dumpsys car_service`로 확인했으나 실차 좌석별 착좌·제어 제공 범위는 아직 별도 확인 대상입니다.
