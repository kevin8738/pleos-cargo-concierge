## 보고서 판정 정책 보완 v21

- **0.6G 이상 판정 보류(D):** 기존 음성 억제의 시제품 임계값을 보고서 해석에도 공유한다. 고G 구간의 원인을 확인하지 못했으므로 비교를 보류하는 정책이며 물리적 최대 G·정확도 통과선·신호 불연속 검출 기준이 아니다. 원래 최대 계산값을 보존한다.
- **입력 출처 표시:** Mock과 확인된 공식 AVD product/API의 모의 입력을 표시한다. 다른 입력은 검증된 실차로 승격하지 않는다. 모의 입력이 섞인 세션은 실주행 평가 불가이다.
- **품질 기록의 의미:** 누락·부분 축·유효하지 않은 입력·수신 순서 역전은 실제 관측한 범위만 기록한다. 최초 기준점과 정상 출처 전환은 정보성 기록이다. 새 속도 차분 수는 실제 이동 시간이나 시간 기반 커버리지 비율이 아니다.
- **보존한 원자료:** v1.1.2의 공식 Console 합성 입력 영상에서 최대4.53G를 관찰했다. 같은 출처의 급변을 수신 차속·시각만으로 실제 감속과 구별할 수 없어 삭제하지 않는다. 이전 영상·로그는 해당 버전 검증 폴더에 보존한다.
