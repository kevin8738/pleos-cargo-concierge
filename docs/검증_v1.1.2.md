# v1.1.2 설정 확인과 신호 전환 검증

2026-10-29 · 기획서 v20 · Pleos release versionCode 5

현재 APK는 공식 AVD에서 설정값을 적용·재조회·복원하고, 동기화나 주행 상태 때문에 복원할 수 없으면 보류합니다. 설정값 확인과 실제 냉방 효과를 화면에서 구분합니다. 실차 보호 효과와 사용자 검증은 아직 없습니다.

## 발견한 문제와 수정

| 발견한 문제 | 수정과 확인 |
|---|---|
| 차속 입력원이 9m/s에서 다른 입력원의10m/s로 바뀌면 출처 간 차이를 실제 가속으로 계산 | 출처가 바뀐 첫 유효 표본에서 종가속 기준·EMA만 다시 시작. 합성 코어 재현의 거짓0.509858G/음성1회가0G/0회로 바뀜. 같은 출처의 실제 수치 변화는 기존0.509858G/1회를 유지 |
| NaN·무한대·음수 차속이 우선순위 유지 시간을 갱신할 수 있음 | 입력값을 확인한 후에만 출처·수신 시각을 갱신. 회귀시험으로 낮은 우선순위의 유효 입력 복귀 확인 |
| 설정값 재조회 성공을 냉방 성공으로 오해 가능 | 요청 수락/설정값 확인을 구별하고 적용 후 조회한 공조 전원 상태를 표시. 평균 온도 명칭을 ‘평균 설정 온도’로 정정 |
| AVD에서 SYNC ON 상태의 조수석 온도 요청이 SYNC를 OFF로 바꿈 | 온도 적용·복원 직전 SYNC를 읽어 명시적 OFF일 때만 허용. ON·미확인·실패는 보류. SYNC나 전원을 자동으로 변경하지 않음 |

출처 전환 시험은 실제 컴파일된 코어에 합성 표본을 넣은 회귀시험입니다. Android 입력원 전환이나 실제 관성 측정 정확도를 확인한 결과는 아닙니다. 설정 적용 후 전원 조회는 그 시점의 기록이고, 복원 후 전원 상태까지 재검사했다는 의미도 아닙니다.

## 확인한 결과

코어136개와 앱 매핑2개, 총138개 시험에서 실패·오류·건너뜀은0입니다. Pleos release 빌드·서명을 검증했으며 lint 오류0·기존경고33입니다. [빌드 기록](검증자료/AVD_v1.1.2/build-summary.json)에 APK 해시가 있습니다.

[공식 AVD 검증](검증자료/AVD_v1.1.2/README.md)은 10개 판정 항목을 통과했습니다. 22→18→22℃ 설정값 재조회, 착좌 미확인 보류, 외부21℃ 유지, 비착좌 상실 후 복원, 전원OFF 안내, SYNC OFF 유지/ON 차단, 외부SYNC 변경 후 명시적 재시도, D단 복원 보류 후P 재시도, 프로세스 재시작 후 미확인 안내를 포함합니다. 검사 완료 후 시험자가 원래 AVD 설정을 복구한 기록은 앱 복원 결과와 분리합니다.

## 아직 확인하지 못한 것

- 제어 허용 조합은 SDK2.3.2·Service2.3.22/code74·crp_avd_arm64/API34뿐입니다. 다른 차량은 빈 좌석을 확정하지 않으며 설정 변경을 보류합니다.
- 공조 설정값은 실제 실내·상자·식품 온도가 아닙니다. 전원을 자동으로 켜지 않고 공유 풍량·풍향을 유지하며 열선ON은 차단합니다.
- 읽기와 쓰기 사이 외부 조작 경쟁, 동일 값 조작의 주체 식별은 남습니다. 재시작 시 원값을 영속 보관하지 않아 자동 복원하지 않습니다.
- AVD에서 강제 getter timeout·권한 회수·다중 좌석 지연·연결 끊김의 모든 조합을 실행하지 않았습니다. 관련 코어 시험을 실차 시험으로 세지 않습니다.
- 실제 G 오차·지연, 보호 효과, 음향 피로, 사용자 재사용, 구매 예산은 미검증입니다. [현장 실행 키트](검증자료/현장검증_진행키트/README.md)의 CSV8개는0행입니다.

[v1.1.1 기록](검증_v1.1.1.md)은 당시 착좌 매핑·SDK readback 수정의 이력입니다. 현재 사용자는 한 번의 VIP 선택으로 시작하고, 복원 실패·미확인 상황에서만 수동 확인을 받습니다.
