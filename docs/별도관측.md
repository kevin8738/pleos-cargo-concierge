Console HTTP 요청 간격을 수신 간격으로 쓰지 않았으며, 어떤 Console 내부 동작이 이 수신열을 만들었는지의 근본 원인까지 확정하지 않습니다. 기존 영상의 **4.49G는 원값 그대로 보존**하고, 당시 raw MotionTrace가 없어 정확한 입력쌍을 소급 복원할 수 없음을 명시합니다. 새 4.4373G로 과거 원인을 확정하거나 정확도 개선을 주장하지 않습니다. `HIGH_G_UNASSESSED`·`SYNTHETIC`·`canCompare=false`와 모의 입력·실주행 평가 불가 표시를 유지합니다.

`native-audio-probe-01`은 VIP 가드가 없는 상태에서 VIP 음향을 끄고 순정 내비 경로를 열고 종료한 **1회 관측**입니다. 응답창 peak S16 **1,842**, RMS **163.2952**를 수신했으므로 무음·발화 부재로 해석하지 않습니다. 그러나 마지막 수신 표본이 경로 종료보다 **4.109676초** 빨라 사전 정의한 전체 경로 창을 덮지 못했습니다. `routeWindowCovered=false`·`amplitudeContrastObserved=false`를 유지합니다. 혼합 출력에는 UI 소리도 있을 수 있어 **순정 발화 귀속·내용과 VIP 음향 경합은 미검증**입니다. 실행·cleanup=true는 관측과 원상 정리가 끝났다는 뜻입니다.
