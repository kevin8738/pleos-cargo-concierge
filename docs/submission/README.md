# 공개 접수양식

제출 대상은 [접수양식](접수양식_VIP조수석.docx)입니다. 개인정보·동의·서명은 공개본에 기입하지 않으며, 대표자 서명 원본은 로컬 제출본에만 둡니다.

제출 APK의 과거 공조 관측 조회와 검증 결과를 반영했습니다. 변경 전 값·요청값·독립 확인값을 구분하고 정차 중 참고용으로 표시합니다. 기록 조회는 차량 값을 적용하거나 복원하지 않습니다.

고유 시험 203개(코어 176·앱 27), 플레이버 중복 포함 실행 228회, 실패·오류·건너뜀 0입니다. release·서명·Mock 컴파일 통과, lint 오류 0·경고 33입니다. 공식 AVD에서 기록 조회 6조건·제어 10조건·전체 동선 9항목과 각 정리를 확인했습니다. [제출 APK 검증](../검증.md)에서 APK 해시·영상·원자료를 확인할 수 있습니다.

별도 관측 APK의 [단일 통합 관측](../검증자료/통합_관측/README.md)과 [수집 진단](../검증자료/수집_진단/README.md)은 미통과 판정을 보존했습니다. [코어 54계산](../검증자료/알림_분석/README.md)은 고정 합성 입력의 분석이며 실차·청취 효과가 아닙니다. 제출 APK의 통과 결과로 합산하지 않습니다.

현장 운전자·실차 G·짐 효과·재사용·구매 결과는 0건이며 빈 CSV 8종과 실행 절차만 준비했습니다. 참가 정보·동의·날짜·필요한 팀원 서명과 심사 접근 확인은 접수 전 남은 항목입니다. 공개본·로컬 서명본 각각 A4 14쪽의 전체 시각 검수와 원양식 구조·화면·메타데이터·서명 위치·체크섬 검사를 완료했습니다.
