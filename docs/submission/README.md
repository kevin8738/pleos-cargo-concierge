# 공개 접수양식

현재 제출 대상은 [접수양식 v22](접수양식_VIP조수석_v22.docx), **A4 15쪽**입니다. 이 폴더에는 개인정보·동의·서명 공란인 공개 사본만 둡니다. 대표자 서명본과 서명 이미지는 로컬 제출 폴더에서 관리합니다. 공개본·서명본은 각 15쪽 렌더와 원양식·메타데이터·화면·서명 삽입 구조 감사를 마쳤으며, 전 페이지 시각 검수와 원본·사본 동기화를 완료했습니다.

v22는 앱 **v1.1.4-pleos / versionCode 7**, 코어 158개·앱 24개, 총 **182개 테스트 통과**, lint 오류 0·경고 33의 결과를 반영합니다. [구현 검증](../검증_v1.1.4.md)과 [AVD 증거 색인](../검증자료/AVD_v1.1.4/README.md)에 제어 10조건, 백그라운드·실패 처리, 정상범위·경고경계 계산, COFFEE 선택의 TTS·차임 실제 출력과 한계를 구분했습니다.

APK는 **47,871,331 bytes**, SHA-256 `8971e207285f333c2c152f185e907ea1d38c01c04369473fc68c8f850f5e023c`입니다. [전체 동선 무음 영상](../검증자료/AVD_v1.1.4/전체동선_무음.mp4)은 82.287311초·2560×1440이며 [현재 A1–A5 화면](../README.md)도 v1.1.4 기록입니다. 영상의 최대 4.49G는 합성 입력 원값이고 ‘실주행 평가 불가·고G 원인 미확인’을 표시합니다. 실제 주행 경고 음향·실차 G 오차·물건 보호·냉방 효과·사용자 검증은 완료 결과로 주장하지 않습니다.

이전 v21 문서 각 15쪽과 v1.1.3의 161개 테스트·82.233889초 영상은 이전 제출 이력입니다. 이전 버전 문서·화면을 현재 APK의 결과로 바꾸지 않습니다.
