# 공개 접수양식

현재 제출 대상은 [접수양식 v23](접수양식_VIP조수석_v23.docx), **A4 15쪽**입니다. 이 폴더에는 개인정보·동의·서명 공란 공개 사본만 둡니다. 대표자 서명본과 서명 이미지는 로컬 제출 폴더에서 관리합니다. v23 공개본 A4 15쪽·대표자 서명본 A4 15쪽의 구조 감사와 전 페이지 시각 검수를 확인했습니다.

v23은 같은 앱 **v1.1.4-pleos / versionCode 7**과 기존 코어 158개·앱 24개, 총 **182개 테스트**, lint 오류 0·경고 33의 결과를 유지하며 추가 관측을 보완합니다. [기존 구현 검증](../검증_v1.1.4.md)·[기존 AVD 증거](../검증자료/AVD_v1.1.4/README.md)와 [주행 음향·flow trace 추가자료](../검증자료/AVD_v1.1.4_추가/README.md)를 구분했습니다.

APK는 **47,871,331 bytes**, SHA-256 `8971e207285f333c2c152f185e907ea1d38c01c04369473fc68c8f850f5e023c`입니다. [기존 전체 동선 무음 영상](../검증자료/AVD_v1.1.4/전체동선_무음.mp4)은 82.287311초·2560×1440이며 [A1–A5 화면](../README.md)과 시뮬레이션 v2.3도 유지합니다. 추가 주행 음향은 ON/OFF와 같은 trip의 합성 도착 보고서까지 연결했지만 ON 원 cleanup 실패·별도 복구를 보존하며 도착 발화는 미수집입니다. 새 trace 최대 4.4372528175G는 이전 4.49G의 원인을 소급 설명하지 않습니다. native 음향 내용·경합, 실차 G 정확도·물건 보호·냉방 효과·사용자 효과는 미확인 또는 미검증입니다.

v22 공개본·서명본 각 A4 15쪽과 당시 검수·패키지는 이전 제출 이력으로 보존합니다.

이전 v21 문서 각 15쪽과 v1.1.3의 161개 테스트·82.233889초 영상은 이전 제출 이력입니다. 이전 버전 문서·화면을 현재 APK의 결과로 바꾸지 않습니다.
