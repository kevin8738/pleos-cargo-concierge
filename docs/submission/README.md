# 공개 접수양식

현재 제출 대상은 [접수양식 v20](접수양식_VIP조수석_v20.docx), **A4 14쪽**입니다. 이 폴더에는 개인정보·동의·서명 공란인 공개 사본만 둡니다. 대표자 서명본과 서명 이미지는 로컬 제출 폴더에서 별도로 관리합니다.

v20은 앱 **v1.1.2-pleos / versionCode 5**, 코어 136개·앱 매핑 2개로 총 **138개 테스트 통과**(실패·오류·건너뜀 0), lint 오류 0·경고 33의 현재 결과를 반영하는 문서입니다. [구현 검증](../검증_v1.1.2.md)과 [AVD 증거](../검증자료/AVD_v1.1.2/README.md)에 조건과 원자료를 정리했습니다.

현재 APK의 크기는 **47,805,319 bytes**, SHA-256은 `427393e17df57381db6ab8e718f41e7514b85a493c13db9716004bfa4bc04cb3`입니다. AVD 10조건 확인은 해당 환경의 소프트웨어 연동 결과이며 실차 G 오차·물건 보호·냉방 효과·실제 음향·사용자 검증 결과가 아닙니다.

[전체 동선 무음 영상](../검증자료/AVD_v1.1.2/전체동선_무음.mp4)은 81.274078초·2560×1440의 연속 AVD 녹화이며, [현재 화면](../README.md)의 A1–A5도 v1.1.2 기록입니다. Console 합성 주행의 불연속 전환으로 표시된 최대 4.53G는 실차 수치나 추정 정확도 근거가 아닙니다. 이전 버전 DOCX와 화면은 해당 버전의 이력으로만 보존합니다.
