현재 제출 대상은 [접수양식 v24](접수양식_VIP조수석_v24.docx), **A4 14쪽**입니다. 개인정보·동의·서명은 공란이며, 사용자가 제공한 대표자 서명 원본은 로컬 제출본에만 둡니다. 공개본·서명본의 원양식 구조, 메타데이터, 실행 화면 5개와 모든 페이지 배치를 확인했습니다.

기존 **182개 시험(코어158·앱24), lint 오류0·경고33**과 APK·시뮬레이션v2.3은 유지합니다. APK는 47,871,331바이트, SHA-256 `8971e207285f333c2c152f185e907ea1d38c01c04369473fc68c8f850f5e023c`입니다. [현재 검증](../검증_v1.1.4.md)에 기존 실행·실패·복구·해시를 연결합니다.
