# 공개 접수양식

현재 제출 대상은 [접수양식 v21](접수양식_VIP조수석_v21.docx), **A4 15쪽**입니다. 이 폴더에는 개인정보·동의·서명 공란인 공개 사본만 둡니다. 대표자 서명본과 서명 이미지는 로컬 제출 폴더에서 별도로 관리합니다.

v21은 앱 **v1.1.3-pleos / versionCode 6**, 코어 158개·앱 매핑 3개로 총 **161개 테스트 통과**(실패·오류·건너뜀 0), lint 오류 0·경고 33의 현재 결과를 반영하는 문서입니다. [구현 검증](../검증_v1.1.3.md)과 [AVD 증거](../검증자료/AVD_v1.1.3/README.md)에 조건과 원자료를 정리했습니다.

현재 APK의 크기는 **47,821,703 bytes**, SHA-256은 `a994a151706c9091562b81b19e35c75b72f6b9b61b403f114ef6e6d26d1d8a84`입니다. AVD 10조건 확인은 해당 환경의 소프트웨어 연동 결과이며 실차 G 오차·물건 보호·냉방 효과·실제 음향·사용자 검증 결과가 아닙니다.

[전체 동선 무음 영상](../검증자료/AVD_v1.1.3/전체동선_무음.mp4)은 82.233889초·2560×1440의 연속 AVD 녹화이며, [현재 화면](../README.md)의 A1–A5도 v1.1.3 기록입니다. 리포트는 최대 3.69G 원값을 보존하고 ‘모의 입력·실주행 평가 불가’와 ‘고G 구간 · 원인 미확인’을 함께 표시합니다. 0.6G 판정 보류는 검증 전 팀 정책(D)이며 물리적 상한이나 오류 검출 기준이 아닙니다. 합성 재생값은 실차 G 정확도·보호 효과의 근거가 아닙니다. 이전 버전 DOCX와 화면은 해당 버전의 이력으로만 보존합니다.
