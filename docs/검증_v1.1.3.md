# v1.1.3 입력 출처와 보고서 판정 검증

2026-10-29 · 기획서 v21 · Pleos release versionCode 6

보고서에서 알려진 모의 입력과 추정 한계를 구분합니다. 최대 계산값을 그대로 남기되, 모의 입력은 실주행 평가에 쓰지 않고 확인하지 못한 구간은 비교를 보류합니다. 실제 관성 측정 정확도·적재물 효과를 검증한 변경은 아닙니다.

## 수정한 문제

| 문제 | 현재 처리 |
|---|---|
| 공식 Console의 합성 속도 급변으로 4.53G가 일반 주행 최대값처럼 표시됨 | Mock·확인된 공식 AVD의 모의 출처를 전달. 혼합 세션도 ‘모의 입력 최대 추정 G’와 ‘실주행 평가 불가’로 표시하고 원값 보존 |
| 큰 값·누락·부분 축을 구별하지 않고 설정 기준과 비교 | 기존 음성 억제와 같은 0.6G 이상을 ‘고G 구간 · 원인 미확인’으로 표시. 입력 단절·부분 축·무효값·수신 순서 역전의 관측 사유를 보존하고 판정 보류 |
| 조향·제동 갱신도 새 속도 차분처럼 해석할 가능성 | 기존 motion 이벤트 수와 실제 새 속도 차분 수를 분리. 수신 중복·짧은 간격·기준점·출처 전환·비유한 계산은 새 차분 수에 합산하지 않음 |
| 새 출처의 기준점 직후 갱신이 불완전 기록으로 잘못 굳을 가능성 | 최초·출처 전환 기준점 사유를 첫 유효 차분까지 유지. 이미 알려진 모의 출처를 UNKNOWN 환경 태그로 지우지 않음 |

**0.6G는 팀의 미검증 시제품 정책(D)**입니다. 물리적 상한·정확도 합격선·사고 감지·불연속 오류 검출 기준이 아닙니다. 같은 출처의 큰 가감속을 임의로 삭제하거나 낮은 최대값으로 바꾸지 않습니다. 첫 기준점과 정상 출처 전환은 정보 기록이며 그 사실만으로 판정을 보류하지 않습니다. 입력 수는 시간 기반 커버리지 비율이 아닙니다.

## 공식 AVD 재현

최종 APK의 공식 AVD 10개 판정이 모두 통과했습니다. 정상 22→18→22℃ 재조회, 착좌 미확인 보류, 외부21℃ 유지, 빈 좌석 확인 상실 후 복원, 전원OFF 안내·유지, SYNC OFF/ON 상태 보존, 외부SYNC 변경 뒤 보류·사용자 해제 후 UI 재시도, D단 보류·P단 UI 재시도, 재시작 시 임의 쓰기 없이 복원 미확인 안내를 포함합니다. ## 남은 검증 경계

- 알려진 모의 출처 이외는 UNKNOWN이며 검증된 실차 입력이라는 뜻이 아닙니다. 원본 센서 시각·수신 지연·차량별 보정·실제 G 오차는 미검증입니다.
- 입력 순서·누락은 앱이 관측한 범위만 기록합니다. 앞단 arbiter가 버린 표본까지 집계했다고 주장하지 않습니다. 같은 출처 급변의 실제 원인은 속도·수신 시각만으로 확정하지 못합니다.
- 제어 허용은 SDK2.3.2·Service2.3.22/code74·crp_avd_arm64/API34 조합뿐입니다. 다른 차량의 점유 미확인을 사용자 확인으로 우회하지 않습니다.
- 공조 설정값은 실제 실내·상자 온도가 아닙니다. 전원·SYNC 자동 변경, 공유 송풍 변경, 열선ON을 추가하지 않았습니다. 읽기/쓰기 사이 경쟁과 프로세스 종료 후 원값 복원은 기존 제한입니다.
- 실제 사용자·실차·음향·보호 효과·사업 검증은0건입니다. 현장 키트는 실행 준비 자료입니다.
