## 현재 검증 · v1.1.4

현재 APK는 **v1.1.4-pleos / versionCode 7 / 47,871,331 bytes**, SHA-256 `8971e207285f333c2c152f185e907ea1d38c01c04369473fc68c8f850f5e023c`입니다. 코어 158개·앱 24개, 총 182개 테스트의 실패·오류·건너뜀은 0이며 release·서명·Mock 컴파일 통과, lint 오류 0·경고 33입니다.

[AVD 증거 색인](검증자료/AVD_v1.1.4/README.md)은 제어, 백그라운드 실행, 실패·종료 처리, 위치 사용 경계, 합성 G 계산, 실제 음향 출력을 분리합니다. 제어 10조건은 정상 22→18→22℃ 재조회, 착좌 미확인 보류, 외부 21℃ 유지, 비착좌 확인 상실, 전원 OFF, SYNC OFF/ON 및 외부 변경, D 보류 후 P 재시도, 재시작 시 미확인 안내·자동 쓰기 없음입니다. Vehicle SDK 2.3.2 / VehicleService 2.3.22(code 74) / crp_avd_arm64 API 34와 Console heartbeat 활성 조건의 결과입니다. 재조회는 공조 설정값이며 실내·짐 온도나 냉방 효과가 아닙니다.

사용자가 시작한 보호 세션의 FGS와 알림을 확인하고 순정 내비 화면의 직접 관측 20.297990초에서 보수적 20개 주기 실행·TBT 6개를 확인했습니다. 위치 검사는 구독·서비스 유형 경계까지입니다. 정상범위·경고경계 시험은 합성 입력의 독립 계산·배지·요청·리포트 대조이며 실제 G 정확도나 품목별 한계를 입증하지 않습니다.

COFFEE 선택 음향 시험에서는 TTS 단독·차임 단독의 수신 PCM 출력과 OFF 대조, 수신 PCM·패킷 메타데이터·WAV 일치를 확인했습니다. 실제 주행 경고 음향, 내비·미디어 중첩, 차량 스피커·운전자 부담은 미검증입니다. 세부 수신 시간 제한과 수정 전 실패·수동 복구 이력도 색인에 보존합니다.
