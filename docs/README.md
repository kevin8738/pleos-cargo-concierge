## 최신 제어 기록 · v1.1.3

[AVD 증거 폴더](검증자료/AVD_v1.1.3/README.md)는 v1.1.3-pleos / versionCode 6의 실제 SDK 제어 기록입니다. Vehicle SDK 2.3.2 / VehicleService 2.3.22(versionCode 74) / crp_avd_arm64 API 34와 공식 Console heartbeat 활성 조건으로 한정합니다. 공조 전원·SYNC 상태는 시험 조건별로 구분하며, 이 환경의 비착좌 해석과 SDK 동작을 실차나 다른 서비스 버전에 일반화하지 않습니다.

확인한 10조건은 정상 온도 22→18→22℃ 재조회, 착좌 미확인 보류, 외부 21℃ 유지, 비착좌 확인 상실 복원, 전원 OFF 표시·유지, SYNC OFF/ON 각각의 운전석·동기화 상태 보존, 외부 SYNC 변경 후 복원 보류·명시적 재시도, D 보류 후 P 재시도, 재시작 시 미확인 안내·자동 쓰기 없음입니다. 단위 검사는 코어 158개·앱 매핑 3개, 총 **161개 통과**(실패·오류·건너뜀 0), release 빌드·서명 검사 통과, lint 오류 0·경고 33입니다.

현재 APK는 **47,821,703 bytes**, SHA-256 `a994a151706c9091562b81b19e35c75b72f6b9b61b403f114ef6e6d26d1d8a84`입니다. 값 재조회는 설정값 확인이며 실제 실내·짐 온도나 냉방 효과가 아닙니다. 적용 후 전원 표시는 과거 조회이고 복원 후 전원 확인은 포함하지 않습니다. 읽기/쓰기 사이 외부 변경 경쟁, 프로세스 종료 후 자동 복원, 실차 G 오차와 실제 음향은 남은 검증입니다.

[전체 동선 무음 영상](검증자료/AVD_v1.1.3/전체동선_무음.mp4)은 **82.233889초·2560×1440·35,460,679 bytes**의 연속 녹화입니다. 한 번의 VIP 선택부터 18℃ 설정 확인, 주행 배지, P 및 운전석 문 열림, 22℃ 복원, 전원 OFF, 착좌 미확인까지 담았습니다. 리포트는 최대 3.69G 원값을 보존하고 ‘모의 입력·실주행 평가 불가’와 ‘고G 구간 · 원인 미확인’을 함께 표시합니다. 0.6G 판정 보류는 검증 전 팀 정책(D)이며 물리적 상한이나 오류 검출 기준이 아닙니다. 합성 재생값은 실차 G 정확도·보호 효과의 근거가 아닙니다. 무음 영상은 실제 음향 재생을 확인하지 않습니다.
