## 최신 제어 기록 · v1.1.1

[AVD 증거 폴더](검증자료/AVD_v1.1.1/README.md)는 현재 APK의 실제 SDK 제어 기록입니다. Vehicle SDK 2.3.2 / VehicleService 2.3.22(versionCode 74) / crp_avd_arm64 API 34 조합과 공식 Console heartbeat 활성·전원 ON 등 준비 조건을 함께 명시합니다. 이 환경의 비착좌 확인 경로를 실차나 다른 SDK·서비스 버전으로 일반화하지 않습니다. 연속 무음 영상 길이는 30.022433초이며 실제 음향·물건 보호 효과를 검증하지 않습니다.

정상 22→18→22℃ SDK 재조회, 착좌 raw 2에서 22℃ 유지, 외부 수동 변경 21℃ 유지, 비착좌 확인 상실 시 22℃ 복원의 4개 사례를 확인했습니다. 단위 검사는 코어 121개·앱 2개로 총 123개 통과(실패·건너뜀 0), release 빌드·서명 검사 통과, lint 오류 0·경고 33입니다. 각 증거의 조건과 한계는 연결된 검증 기록을 따릅니다.
