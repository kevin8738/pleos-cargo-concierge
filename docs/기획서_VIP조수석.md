앱명 / 프로젝트명: **VIP 조수석 (Cargo Concierge)**

## 1. 앱 한 줄 소개
이미 실은 소중한 짐을 정차 홈에서 한 번 선택하면, 품목별 주행 코칭·도착 챙김과 지원되는 차량 설정·복원을 이어 주는 Pleos 차량용 앱입니다.

## 2. 기획 배경

**케이크를 실은 뒤부터 챙겨 내릴 때까지, 운전자가 맡는 일을 한 흐름으로 연결합니다.** 케이크 상자를 조수석에 놓으면 히터·열선을 확인하고, 코너의 쏠림을 신경 쓰고, 도착해서 상자를 챙기고 설정도 되돌려야 합니다. VIP 조수석의 제안은 **‘VIP 선택 → 설정 결과 확인 → 쏠림 코칭 → 도착 챙김·복원’**입니다. 물건 고정과 차량 운전은 운전자가 맡습니다.

**기본 동선은 선적재 → 정차 중 앱 열기 → 현재 자리의 최근·추천 VIP 1탭입니다.** 현재 자리가 다르면 자리 선택 1탭을 더합니다. 시작 자체는 운전자가 기억해야 합니다. 앱 실행 전 도어 이력·백그라운드 자동 호출은 연결되지 않았고, 도어 제안은 앱이 신호를 받는 동안만 제공됩니다. 따라서 검증할 약속은 ‘앱을 열 필요까지 없앰’이 아니라 **시작한 뒤의 설정 확인·운전 코칭·종료 확인 부담을 줄이는가**입니다.

**현재 제어 범위는 확인된 AVD 조합입니다.** 실차와 미확인 SDK·차량 조합에서는 차량 설정을 보류하고, 유효한 신호로 가능한 코칭·챙김을 제공합니다. 실차 G 추정 성능도 아직 검증하지 않았습니다. 정차·빈 좌석·항목별 지원 조건을 모두 확인했을 때만 설정을 요청하며, 설정값을 다시 읽었다는 사실과 공조 작동·짐 보호 효과를 구분합니다.

**필요한 운반 기회에 켜는 도구로 검증합니다.** 초기 고객은 조수석에 픽업 물건을 싣는 Pleos 차량 운전자이며, 가족 운전자를 우선 탐색합니다. 케이크는 첫 경험, 퇴근길 포장음식은 반복 기회를 살필 장면입니다. 포장음식 주 1~2회는 팀 가정(D)입니다. 공조 변경 없이도 품목을 선택해 쏠림 코칭과 하차 챙김을 받는 일이 앱 실행 부담보다 유용한지가 핵심 가설입니다. 매일 접속을 요구하지 않고 **운반 기회 중 자발 시작·완료 비율**을 주지표로 봅니다. 현재 사용자 과업·재사용 결과는 0건입니다.

**차량 안에서 연결하는 가치.** 도어·기어·차속·착좌 신호로 시작·주행·종료 조건을 판단하고, 좌석별 지원 항목을 요청한 뒤 결과를 다시 확인합니다. 차속·조향으로 추정한 G와 차량 화면·스피커를 사용하며, 내비 도착과 P단·운전석 도어를 챙김·복원에 연결합니다. 스마트폰의 가속도 기록보다 낫다고 입증한 것이 아니라, **좌석 설정과 이동 전후의 처리를 함께 제공하는 차량 내부 연동**을 제안합니다.

| 기존 방식 | 사용자가 맡는 일 | VIP 조수석의 제안 |
|---|---|---|
| 수동 공조·시트 조절 | 항목별 변경과 종료 후 복구를 기억 | 품목·자리 선택에 요청을 묶고 설정 확인·복원 결과 표시 |
| 개별 음성 차량 제어 | 온도·열선 명령과 종료 시점을 구성 | 앱 내에서 품목·자리를 말하거나 최근 VIP를 선택해 세션 시작 |
| 주행 기록·운전 점수 | 주행 뒤 기록을 해석 | 품목별 초기 한계로 짧게 코칭하고 도착 후 최대 추정 G·횟수 확인 |

| 보냉백·완충재·적재 고정 | 물건을 물리적으로 보호 | 이를 사용한 상태에서 설정·운전 습관·챙김을 보조 |

위 표는 사용 단위의 비교입니다. 순정 기능의 제공 여부·감지 범위를 특정 차종에 가정하거나 스마트폰 대비 독점성을 주장하지 않습니다. Pleos Vehicle·NaviHelper·음성 어댑터를 구현해 별도 적재물 센서·서버 없이 이 흐름을 검증하고 있습니다. 평소 방식과 앱 방식의 시작·종료까지 걸린 시간, 놓친 항목, 상태 오해를 비교해 실제 부담 감소를 판단합니다.

대표 검증은 **케이크, 음료·국물, 포장음식, 일반 짐**에 집중합니다. 구현된 보호 분류 9종은 유지하되, 꽃·반려동물·전자기기 등의 품목별 효능까지 검증한 것으로 확장하지 않습니다.

**알림과 리포트의 단위.** 6회·3회·8초는 **세션 단위의 앱 주행 안내 요청 정책**이며 실제 스피커 재생 완료나 차량 전체 소리의 상한이 아닙니다. 중간 정차 후 같은 VIP로 다시 시작해도 통계와 알림 예산을 새로 시작합니다. 30분은 검증용 관찰창이며, 그 안의 세션 수·재시작 수·누적 요청과 실제 소리·순정 내비 중첩을 따로 기록합니다. ‘30분당 최대 6회’를 코드 보장으로 사용하지 않습니다.

**리포트의 입력 출처와 판정 범위.** 알려진 공식 AVD·Mock 입력이 포함되면 화면에 ‘모의 입력’과 ‘실주행 평가 불가’를 표시하고 계산한 최대값은 그대로 보존합니다. 0.6G 이상 추정 구간, 신호 누락·일부 축만 계산한 기록 등은 비교 판정을 보류합니다. 0.6G는 음성 억제와 공유하는 팀의 시제품 정책(D)이며 물리적 상한·입력 오류 검출·사고 판정 기준이 아닙니다. 같은 출처의 큰 속도 변화를 임의로 삭제하거나 더 낮은 최대값으로 바꾸지 않습니다. 실차 G 정확도와 적재물 효과는 별도 검증 대상입니다.

**분류별 초기값과 요청.** 근거 등급은 A=공식 자료·직접 측정, B=문헌·지침, C=물리 유도, D=팀 가정입니다. 아래 G는 파손·넘침의 확정 한계가 아니라 코칭 초기값이며, 포장·고정·시트 조건별 검증이 필요합니다.

| 보호 분류 | 기본 한계 | 현재 프리셋 요청 | 근거·적용 경계 |
|---|---|---|---|
| 케이크·디저트 / 신선식품 | 0.15G | 케이크 조수석 18℃·열선/통풍 OFF, 지원 시 풍량·풍향. 신선식품은 독립 후석 존 18℃ 요청 | C+D: 마찰계수 0.3 가정의 절반. 18℃는 설정값이며 상자 내부 온도·냉장 보관을 뜻하지 않음 |
| 뜨거운 음식 / 음료·국물 | 0.12G | 뜨거운 음식은 통풍 OFF·독립 존 송풍 OFF 요청. 음료·국물은 공조 변경 없음 | C+B+D: 용기 여유 높이·폭 기반 초기값. 열선 2단은 분류 정의에만 있고 ON은 기존 동의와 무관하게 차단 |

| 깨지기 쉬운 물건 | 0.12G | 공조 변경 없음 | C+D: 단순 전도 모델 기반. 파손 강도·완충재 성능 측정값이 아님 |
| 전자기기·악기 | 0.25G | 열선 OFF 요청 | C+D: 포장된 강체 가정. 종류별 충격 내성으로 일반화하지 않음 |

**실패 시 행동.** 주행 또는 AAOS UX 제한에서는 목록·설정 조작을 숨기며 실행 직전 정차 조건을 재검사합니다. 차속 수신 후 2초가 지나면 추정을 멈추고 조향만 만료되면 가감속만 추정합니다(D). 공조·시트를 요청한 세션에서 빈 좌석 확인을 잃으면 종료하고 정차·현재 값 확인을 거쳐 조건부 복원을 요청합니다. 설정 변경이 없는 G 세션은 유지합니다. 실행 중 복원 실패는 새 적용을 보류하고 P 정차 후 재확인 경로를 제공합니다. 원래 값을 모르면 임의 기본값으로 복원하지 않습니다.

**기록과 개인정보.** 앱 자체 서버·외부 분석 수집 모듈은 없습니다. 최근 VIP 이름·분류와 설정은 차량 로컬에 저장·삭제하며 리포트는 현재 세션 화면에서 봅니다. 인식 텍스트는 UI·진단 로그에 나타날 수 있습니다. Pleos 음성·위치 서비스의 데이터 처리는 플랫폼 정책 범위이며, 향후 연구 기록은 별도 동의·최소 수집·보관 기간을 정해 진행합니다.

## 4. 주요 사용 시나리오

**A — 케이크를 먼저 싣고 귀가하는 기본 흐름.**
1. 케이크 상자를 조수석 시트 위에 안정적으로 놓은 뒤, 운전자가 P단·정차 상태에서 앱을 엽니다. 현재 자리가 조수석이면 최근·추천의 케이크를 1탭 선택합니다. 다른 자리일 때만 자리 변경 1탭을 더합니다.
2. 0.15G 코칭 세션이 시작됩니다. 확인된 AVD의 빈 좌석에서는 조수석 18℃·열선 OFF 등의 설정 결과를 표시합니다. 공유 풍량·풍향은 유지합니다. 실차·미확인 조합에서는 설정을 보류하고 유효 신호로 가능한 코칭·챙김을 사용합니다. ‘설정값 확인’은 냉방 작동이나 상자 내부 온도 확인과 다릅니다.
3. 출발하면 정적 배지를 표시하고 정책이 허용한 효과음·짧은 코칭을 제공합니다. 운전자는 교통 상황을 우선합니다. 실제 케이크 상태를 감지하거나 파손 여부를 판정하지 않습니다.
4. 내비 도착 뒤 P단·정차 또는 P단·정차 중 운전석 문 열림에 챙김과 복원을 요청합니다. 설정값 복원이 확인되면 짧은 완료 표시로 끝내고 케이크를 챙깁니다. 실패·미확인 항목이 있을 때만 해당 항목의 수동 확인을 안내합니다.

**B — 퇴근길 포장음식과 음료를 반복 운반.** 최근·추천 VIP를 선택해 포장음식은 0.12G 코칭·챙김을 사용합니다. 열선 ON은 차단하고 공유 송풍은 유지하므로 보온 효과를 약속하지 않습니다. 음료·국물도 0.12G이며 공조를 바꾸지 않습니다. 다음 운반 기회에 스스로 다시 켜는지가 반복 사용 검증의 핵심입니다. 코칭이 불편하면 정차 후 음성을 끄거나 종료할 수 있습니다.

- **근거와 권리.** `docs/근거_EVIDENCE.md`에 숫자·초기값·정책·사업 가정의 출처와 A/B/C/D 등급을 제공합니다. 문헌·물리식은 적재물 실증을 대신하지 않습니다. 아이콘·일러스트는 자체 벡터 키트, 서체는 Pretendard(OFL)입니다.
