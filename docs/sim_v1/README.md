# VIP 조수석 (Cargo Concierge) — 3D 주행 시뮬레이션

「VIP 조수석」의 핵심 아이디어를 브라우저 3D로 보여 주는 설명용 시뮬레이션입니다.
**사람 기준 0.40 G가 아니라 케이크 기준(한계 0.15 G의 75 % 이내)으로 운전하면 케이크가 무사하다**는 것을
같은 코스를 두 방식으로 달려 비교합니다.

## 실행

빌드나 npm 설치는 필요 없습니다. ES 모듈과 importmap을 쓰므로 `file://`이 아니라 로컬 서버로 엽니다.

```bash
cd docs/sim_v1
python3 -m http.server 8787
# 브라우저(Chrome 최신)에서 http://127.0.0.1:8787/
```

Three.js r160은 jsdelivr CDN(`three@0.160.0`)에서 받으므로 인터넷 연결이 필요합니다.

## 화면 읽는 법

- **좌하단 계기**: 속도, 핸들각, 횡 G / 종 G / 총 G, 한계 G 바(노란 눈금 = 한계의 80 %, 흰 선 = 한계, 바 끝 = 한계의 2배), 최대 G, 손상도, 코칭 n/3, 랩타임, 기어.
- **우하단 센터 디스플레이**(앱 화면 스타일): 정적 배지 OK/NEAR/OVER, 말풍선(음성 코칭·사전 안내·도착 안내), 이벤트 로그 5줄. 같은 내용이 차 안 센터 디스플레이(캐빈 캠)에도 그려집니다.
- **케이크 상자**: 조수석 위 흰 상자와 금색 리본. 상자 위 작은 막대가 손상도입니다. 총 G가 0.30을 넘으면 관성 방향으로 밀리고(최대 8 cm) 기웁니다.

## 무엇이 실제 앱 로직이고, 무엇이 단순화인가

### 앱과 같은 것 (`js/physics.js`, `js/monitor.js`)
- **G 추정식** (`core/physics/GEstimator.kt`와 같은 식): 바퀴각 δ = 핸들각 / 15, 축거 L = 2.9 m,
  a_lat = v²·tan(δ)/L, a_lon = dv/dt, 총 G = √(a_lat² + a_lon²) / 9.80665, EMA 0.5.
- **분류별 한계 G**: 케이크·디저트 0.15 / 뜨거운 음식 0.12 / 꽃·식물 0.20 / 신선식품 0.15 / 음료·국물 0.12 / 깨지기 쉬운 물건 0.12 / 전자기기·악기 0.25 / 반려동물 0.20 / 일반 짐 0.20.
- **배지**: OK(< 80 %) → NEAR(≥ 80 %, 진입 순간 짧은 비프 1회, 화면 전환 없음) → OVER(> 100 %, 음성 코칭).
- **음성 코칭 제한**: 주행당 최대 3회, 총 G ≥ 0.6(긴급 조작) 중에는 말하지 않음, 15 km/h 미만 선회(주차) 중에는 말하지 않음.
- **사전 안내(F4)**: R30 커브 100 m 전 "이번 코너는 N km/h 이하로", N = √(한계 G · g · R) · 3.6을 5 km/h 단위로 반올림(케이크 23.9 → 25).
- **도착**: 주차장에서 정지(기어 P)하면 "조수석 케이크 챙기세요" + 주행 리포트(최대 G, 코칭 횟수, 손상도, 랩타임).
- 음성은 TTS 없이 말풍선 텍스트로, NEAR 효과음만 WebAudio 비프로 냅니다.

### 시뮬레이션용 단순화
- **차량 운동**: 타이어 미끄러짐이 없는 운동학적 자전거 모델. 직접 운전에서 큰 핸들각을 고속으로 넣으면 현실에서는 불가능한 G도 나옵니다.
- **케이크 손상 모델**: 매 스텝 `손상도 += max(0, 총 G − 한계 G) × dt × 400 %`. 실제 케이크 물성 모델이 아닙니다.
- **상자 밀림**: 총 G > 0.30일 때만 관성 방향으로 밀리고, 마찰 때문에 저절로 제자리로 돌아오지 않는다고 가정했습니다.
- **자동 운전자**: 속도 프로파일(커브 속도 = √(목표 횡 G · g · R), 제동 한계의 85 %로 거꾸로 연결) + 순수추종 조향.
  사람 기준(A)은 코너 0.40 G·가속 1.4·제동 3.0 m/s²(커브 직전에 늦고 세게 제동). 케이크 기준(B)은 코너 = 한계의 75 %, 가감속 ≤ 1.0 m/s²(한계의 70 % 이하), 선회 중 합성 G 예산 = 한계의 78 %. 케이크 결과: A 0.42 G·손상 100 %·R30 39 km/h, B 0.117 G·손상 0 %·NEAR 0회·R30 21 km/h.
- **코스**: 정삼각형 모서리를 R60 → R120 → R30 원호로 둥글린 닫힌 루프(1바퀴 약 1.40 km). 차는 오른쪽 차로 중앙을 달립니다.
