# 합성 안내 요청 분석: 단일 실행 수치 요약

원결과를 읽어 작성한 파생표다. 재실행·입력튜닝 없음. 54개 계산 케이스 PASS는 D 가정 입력에 대한 C 엔진 불변량 검사를 뜻하며 실제 청취/현장 관측은 각각 0이다. root의 독립 raw 재계산 검토는 별도다.

- 고정 프로파일 길이 120초; 기준 입력100ms, Tick250ms. 비교는 반복 프로파일에만50/250ms.
- 한계그룹: 0.12=HOT_FOOD/COFFEE/FRAGILE; 0.15=CAKE/GROCERIES; 0.20=FLOWERS/PET/GENERAL; 0.25=ELECTRONICS. 동일 그룹 수치 일치.
- `진입 W/O`는 speed 관측격자의 순간 WARN/OVER 진입수다. OVER→WARN 하강도 WARN 진입에 포함하므로6펄스에서 WARN12가 가능하다. 표시 배지 전이는 원summary에 별도 보존했다.
- `후보 W/O`는 해당 순간영역에서 생성된 gate 후보 총수다. 이벤트 주기에 따라 반복 증가하며 실제 울릴 소리의 개수가 아니다. 억제된 후보의 음성/효과음별 원목록은 공개 API로 복원하지 않는다.
- `허용 음성/효과음`은 reducer 요청수다. 시간은 주행 시작 후 초; 미도달은 null이며 최초6회 도달과 최초TRIP_LIMIT는 별개다.

해석 범위: 0.15G 그룹의250ms 입력에서는 관측이 WARN을 건너뛰고 OVER로 진입해 음성3/효과음3이 허용되었다. 50/100ms에서는 먼저 허용된 WARN 효과음 뒤 공통 cooldown이 OVER 음성을 억제해 음성0/효과음6이었다. 같은 최대G여도 신호 표본화가 안내 종류를 바꾼다는 합성 민감도다. 실제 SDK 주기나 청취 부담의 측정은 아니다.

지속OVER는 voice3에44.4~44.8초에 도달했지만 전체6에는 도달하지 않았다. 급감속은 최대1.273400495G와HIGH_G_UNASSESSED를 보존했고 EMERGENCY34요청 억제/프로파일 전체음성1을 기록했다. 이를 짐 안전·긴급상황 정확도 PASS로 바꾸지 않는다.
