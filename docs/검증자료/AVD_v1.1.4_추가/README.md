## 영상과 음향의 단위

`driving-audio-01/both-on/continuous-silent.mp4`는 99.969744초·2560×1440·34,463,362바이트·오디오 스트림 0개의 원본이다. SHA-256 `12aacbd2778238783a0b151ef6b98b7d6323085141d46f3804bd4977bb8424bc`. 원래 demux 시간축으로 전체 디코딩했으며 오류 출력이 없다. 후처리 음성을 합성하거나 수신 PCM을 임의로 영상에 맞추지 않았다.

`capture/audio.wav`와 PCM은 에뮬레이터 출력에서 수신한 표본을 이어 붙인 파일이다. ON 수집은 벽시계 40.005296초에 PCM 20.259792초·수신 메타데이터 3,386건이다. 연결 WAV의 길이를 연속 녹음 시간이나 발화 길이로 해석하지 않는다. 이번 캡처에는 개별 사후 분할 조각 파일이 없으며, 이전 v22의 5,090개 사후 조각과 구분한다. 네 원파일(메타데이터·PCM·WAV·표본 분석)을 그대로 보존한다.

PCM은 혼합 에뮬레이터 출력이다. 앱의 허용 요청 시각, 수신 표본, 설정별 대조와 SDK 시작·완료를 함께 보며 PCM 하나만으로 앱 귀속·명료도·물리 스피커 출력을 단정하지 않는다. 시계 보정은 단일 관측이며 장기 drift를 측정하지 않았다. TTS 콜백에는 요청 ID가 없어 시각·순서로 연결한 한계가 있다. 도착 발화는 PCM 수집 뒤여서 이번 실제 음향 검증에 포함하지 않는다.

별도 입력 추적의 [무음 원본](flow-trace-01/continuous-silent.mp4)은 54.319433초·18,622,758바이트·2560×1440·오디오 스트림 0개다(SHA-256 `c52e324424fe6b2bfb3bd9aa0e7437dad20c028b8c4022b5a53162c84b20e6ed`). 두 영상의 초기 기본 null mux 검사에서 나온 DTS 메시지와 원래 demux 시간축으로 디코딩한 오류 0 결과를 모두 보존한다.

내비 관측의 3,453개 수신 메타데이터와 PCM 9.045438초는 벽시계 40.010816초 안의 일부 표본이다. UI 경로 구간에서 peak S16 1,842가 관찰됐지만 전체 구간 수집 조건을 충족하지 않아 대비 판정은 false다. 자동 전사는 개인정보 확인 보조에만 사용했으며 청취 시험·발화 귀속·음향 경합의 근거로 사용하지 않는다.
