# 현장검증 진행 키트

**상태: 준비 완료·실제 데이터 미입력.** 아래 CSV는 모두 헤더만 있으며 참가자, 시험, 인터뷰 또는 효과의 결과를 담지 않는다. 실제 참가자와 허용된 시험 환경·계측기·구매 및 채널 담당자 관찰이 필요하다. 이 키트 작성은 검증 실시로 세지 않는다.

기준 문서는 [실측·사용자 검증 실행표](../실측_사용자검증_실행표.md)다. 표본 수, 반복, 기간, 통과선은 그 문서의 **D등급 팀 결정 기준**을 참조한다. 새 과학적 기준이나 앱 동작을 추가하지 않는다. 내부 v18 재심사에서 확인한 증거 공백을 기록 가능한 항목으로 옮겼다. 내부 심사 원문은 로컬 검토자료에서 관리한다.

## 바로 실행하는 순서

1. 실행표 §1–2의 제어·복원 선행 조건을 확인하고 `01_실행세션.csv`에 실제 버전·환경·관찰 범위를 적는다. 원값 읽기 정책을 우회하지 않는다. 제어 검증이 부족한 상태에서 사용자 이해만 볼 경우, 정차 시연/Mock으로 범위를 표시하고 차량 제어 성공으로 보고하지 않는다.
2. [정차 과업 진행 대본](정차과업_진행대본.md)을 그대로 읽고 `02_정차과업.csv`에 시도마다 한 행을 기록한다. 성공 방법은 먼저 설명하지 않는다.
3. 일상 운반 기회 관찰은 `03_관찰일.csv`와 `04_운반기회.csv`를 함께 쓴다. 운반 기회가 없는 날과 기록이 빠진 날을 구별한다. 주행 후 안전한 정차 상태에서 기록한다.
4. 구매·채널 담당자와 실제 대화할 때 [인터뷰 질문](구매채널_인터뷰.md)을 사용한다. `05_인터뷰답변.csv`에는 익명 코드·질문별 실제 답변과 확인 근거를 남긴다. 연락·모집은 이 키트에 포함하지 않는다.
5. G·음향 시험은 실행표 §4의 조건을 먼저 충족하고 `06_계측세션.csv`, `07_G판정표본.csv`, `08_실제음향.csv`를 기록한다. 실차 계측, 시험대, AVD, 합성 입력을 구분한다.
6. 원자료를 검토한 뒤 실행표 §7에 결과·한계·범위 축소 여부를 연결한다. 빈 칸, 준비 자료, 코드 검사 통과를 실측 결과로 바꾸지 않는다.

## 파일과 기록 단위

| 파일 | 한 행의 단위 | 채우는 시점 |
|---|---|---|
| `01_실행세션.csv` | 하나의 정차 관찰 또는 계측 실행 | 실행 전 조건과 실행 후 범위 확인 |
| `02_정차과업.csv` | 한 참가자의 한 과업 시도 | 시도 직후 |
| `03_관찰일.csv` | 참가자 한 명의 하루 관찰 상태 | 기회가 없는 날도 사후 확인 |
| `04_운반기회.csv` | 실제 운반 기회 한 번 | 시작하지 않은 기회도 기록 |
| `05_인터뷰답변.csv` | 한 인터뷰의 질문 하나에 대한 답변 | 대화와 근거 확인 후 |
| `06_계측세션.csv` | 동기화·센서·표본 규칙이 같은 실행 | 계측 전 설정, 종료 후 누락 확인 |
| `07_G판정표본.csv` | 미리 정한 시각 표본 하나 | 원시 시계열을 고정 규칙으로 정렬한 후 |
| `08_실제음향.csv` | 재생 요청·실제 음향 사건 하나 | 녹음/로그 확인 후 |

[기록 규칙](기록규칙.md)에 열 정의·분모·판정 범위를 정리했다. 파일은 UTF-8 CSV이며 빈 데이터 행도 넣지 않았다. 헤더 검증 결과는 [템플릿 검사](템플릿검사.json)에서 확인한다.

## 데이터의 범위

참가자·차량·담당자는 임의 코드로 적으며 실명, 연락처, 번호판, 정확한 이동 경로, 계정 ID를 적지 않는다. 참여 여부·기록 범위·보관 기간·철회 경로를 실제로 확인한 뒤 관찰한다. 동의했다는 상태를 미리 채우지 않는다. 답변 인용과 자료 파일명에서도 식별 정보를 제거한다.

이 폴더에는 배포 가능한 빈 서식과 진행 대본만 보관한다. 실제 조사에는 서식을 별도의 로컬 작업 폴더로 복사해 사용하고, 원자료·동의 기록·작성한 CSV를 Git에 넣지 않는다. 심사 문서에는 검토한 익명 집계와 재현 가능한 조건·한계만 별도로 반영한다. 기존 결과가 있다면 출처와 시점을 확인해 연결하며 새 관찰로 중복 집계하지 않는다.

4주 재사용과 D30은 실제 기간을 기다려야 한다. D30은 첫 완료 후 28–34일을 확인해야 하므로 28일에 최종값으로 확정하지 않는다. 사용자 과업 관찰은 물건 보호 효과의 실측을 대신하지 않는다.
