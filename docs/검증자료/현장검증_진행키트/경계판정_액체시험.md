# 경계 판정·액체 시험 사전 명세

상태: **실행 준비, 실제 자료 0건**. 아래 수치와 중단·확대 결정선은 모두 **D등급 팀 가정**이다. 기기·대상·허용 장소를 확보한 뒤 실행 전에 책임자와 검토자가 조건·파일 해시를 고정한다. 현재 앱의 임계값·가드·음향 정책을 바꾸지 않는다. 기존 [실측·사용자 검증 실행표](../실측_사용자검증_실행표.md)와 [기록 규칙](기록규칙.md)에 덧붙이는 절차다.

## G 경계: 비교 가능한 값부터 고정

품목 한계 `L`에 대해 주의 경계는 `0.8L`, 초과 경계는 `L`이다. 경계 혼동행렬은 현 제품의 `totalG = hypot(횡G, 종G)`에 대응하는 **합성 크기**로 고정한다. 기준 센서의 같은 차체 좌표축·중력 제거·대상 대역을 명세하고 그 합성 크기와 비교한다. 부호가 있는 종축·횡축 오차는 별도 진단으로 보고하며 음수 감속을 `g ≥ B`에 그대로 넣지 않는다. 서로 다른 축이나 필터의 수치를 직접 비교하지 않는다. 현재 화면의 3초 배지 유지와 음향 억제는 순간 G 분류와 분리한다. 배지가 남았다는 이유만으로 순간 추정의 FP를 만들거나, 예산으로 억제된 음성을 추정의 FN으로 세지 않는다.

| 항목 | 실행 전에 고정할 규칙(D) |
|---|---|
| 조건별 분모 | 품목 한계 그룹 × 가속/감속/좌/우 선회 × 검증한 차량·파라미터. 기존 각 5회 반복을 유지하며 반복별 결과와 합계를 함께 보고한다. 서로 다른 조건의 좋은 결과로 미달 조건을 상쇄하지 않는다 |
| 표본 시각 | 기준 센서·앱 원신호를 연속 보존하고 100ms 고정 격자에서 비교한다. 장비가 이를 지원하지 않으면 실행 전에 새 주기를 명시하고 판을 바꾼다. 원본을 바꿔 재실행 결과처럼 만들지 않는다 |
| 정렬·누락 | 실행 전후 동기화 표식으로 시간차와 변화를 기록한다. 시행별 오차 최소화 정렬은 하지 않는다. 양쪽 유효 표본으로 둘러싸이지 않거나 간격이 사전 명세한 센서 주기의 2배를 넘으면 보간하지 않고 판정불가로 둔다. 실제 앱 freshness 초과도 별도 기록한다 |
| 기준 불확도 | 교정·영점·축 정렬·시각 오차가 G에 주는 범위와 산정 근거를 기록한다. 합성 불확도를 모르면 0으로 두지 않고 판정불가로 둔다. 시간 오차의 영향은 해당 구간 변화율과 함께 검토하며 측정하지 않은 정확도를 사양값 하나로 확정하지 않는다 |
| 이진 판정 | 각 경계 `B`에서 기준 구간 `[g−u, g+u]`의 하단이 `B` 이상이면 양성, 상단이 `B` 미만이면 음성. 경계에 걸치면 그 경계만 판정불가. 앱 순간값은 `g_app ≥ B`를 양성으로 두어 TP/FP/FN/TN을 계산한다 |
| 보고 단위 | 주의·초과 각각 FP/(FP+TN), FN/(FN+TP), 네 개 원수, 유효·판정불가 표본수와 사유를 제시한다. 분모 0이면 미산출이다. 연속 표본을 독립 시행 수나 모집단 정확도로 부르지 않는다 |
| 지속 시간 | 같은 경계의 연속 FP 또는 FN을 한 구간으로 기록하고 고정 격자 시작~다음 상태 시각으로 길이를 계산한다. 누락·불확정 표본에서 구간을 끊고, 가려진 지속시간은 미확정으로 남긴다. 최대 길이와 0.5초 이상 구간 수를 함께 보고한다 |

**탐색용 확대 결정선(D):** 기존 조건별 p95 절대오차 ≤0.03G·시간차 ≤0.5초만으로 통과시키지 않는다. 위의 각 경계에서 FP·FN 각각 ≤5%, 판정불가 비율(경계별 판정불가 격자수 / 사전 관찰창의 전체 예정 격자수, 누락 포함) ≤10%, 0.5초 이상 연속 초과 FN 0구간을 추가 후보 기준으로 둔다. 양성·음성 각각 유효 표본 100개 이상이 3회 이상의 반복에 걸쳐 있어야 확대 결정선을 판정하며, 표본 부족 조건도 원수·누락·관측값을 보고한다. 이는 정밀도·표본 독립성·통계적 검정력의 보장이 아니다. 조건을 확보하려고 실제 도로에서 급조작하지 않는다. 표본 부족이면 기간·허용 시험 조건을 재설계하고 판정 보류한다.

5%·10%·0.5초는 초기 검토를 위한 탐색용 팀 결정선이며 검증된 허용 위험률이 아니다. 통과해도 관찰한 조건에서 후속 시험을 진행할 근거만 얻는다. 미달 조건은 해당 조건의 코칭 성능 주장과 실차 지원 확대를 보류한다. 파라미터 보정·범위 축소·초기값 재설계 중 조치를 기록한 뒤 새 판으로 재시험한다. 기존 결과·실패와 사전 명세는 보존한다. 앱에 조건별 자동 차단 기능이 이미 있다는 뜻은 아니다.

`06_계측세션.csv`에는 이 명세의 고정 사본을 `decision_rule_path`로 연결한다. `07_G판정표본.csv`의 두 경계 판정과 사유를 채우고, 반복별 집계·연속 오판 구간은 원자료 옆 별도 결과 파일로 만든다. 현재 두 CSV를 포함한 8개 템플릿은 데이터 0행을 유지한다.

## 음료·국물: 대표 포장 2종으로 시작

열선·공조와 분리한 **허용 시험대의 동적 포장 시험**을 준비한다. 첫 시료는 상온의 물이며 뜨거운 액체·실제 도로·생물은 사용하지 않는다. 물 결과는 국물의 점도·유분·온도 또는 모든 음료를 대표하지 않는다. 같은 차량 G가 시트·용기에 그대로 전달된다고 가정하지 않고 시험대와 용기의 입력·움직임을 각각 기록한다.

| 고정 항목 | 최소 설계(D)·측정할 실제 값 |
|---|---|
| 포장 | 실제 확보한 음료 컵 1종과 포장 용기 1종. 내부 폭·높이·모양·재질, 뚜껑/구멍/밀봉 방식, 용기·물 질량을 측정하고 제품을 익명 코드로 구분 |
| 충전·뚜껑 | 정지 수면에서 가장 낮은 넘침 경로까지 여유 높이 5mm/10mm를 계획값으로 둔다. 실제 높이·오차·충전량을 기록하고 용기에 맞지 않으면 제외. 첫 판은 정상 사용의 맞는 뚜껑을 닫은 상태로 고정하며 개방 용기 시험을 합산하지 않음 |
| 지지 조건 | 용기에 맞는 캐리어 있음/없음, 동일 받침 표면·방향·장착 위치. 시험대 밖 이탈을 막는 2차 받침은 시료 운동을 방해하지 않는 범위를 고정하고 사진 기록 |
| 최소 반복 | 2종 × 여유 높이 2개 × 캐리어 2조건 × 3회 = 24회 계획. 이는 대표성·효과 보장의 표본 수가 아님. 중단·시료 교체·재밀봉도 별도 회차로 남김 |
| 동적 입력 | 장비가 허용하는 동일한 수평 가감속 파형을 실행 전에 파일·SHA로 고정. 한 회차에 목표 0.08/0.12/0.16G의 세 단계를 모두 포함. 첫 판은 용기의 전후 수평축으로 고정하고 상승·유지·감쇠 시간, 단계 사이 정지 수면 회복·반복 간 안정화 조건을 장비 확인 후 명세해 실제 기준 센서 파형을 보존. 방향 변경은 별도 조건. 미확보 장비의 성능·실행 가능성을 현재 확정하지 않음 |
| 시료 초기화 | 매회 새거나 변형된 포장 여부, 초기 질량·여유 높이·뚜껑 결합과 정지 수면을 확인. 순서는 조건별로 섞어 사전 저장하고 결과를 본 뒤 유리한 반복만 선택하지 않음 |

**종점은 세 가지로 나눈다.** ① 용기/상자 이동거리·기울기·전도(영상 기준점과 길이 오차), ② 용기 밖으로 나온 액체의 관측과 회수 질량(저울 영점·회수 손실·오차 포함), ③ 뚜껑 이탈·벌어짐이다. 물방울 관찰과 계량 한계 미만을 구분하고, 검출하지 못했다는 결과를 누액 0g로 확정하지 않는다. 케이크는 별도로 상자 이동과 내부 층/크림 변위를 각각 기록한다. 물 시험을 케이크 효과로 옮기지 않는다.

누액·전도·포장 손상, 고정/계측 이상 또는 장비 제한 초과가 생기면 해당 회차를 중단하고 직전까지의 입력·종점을 남긴다. 중단 전에 도달하지 않은 단계는 미노출로 남겨 해당 단계의 성공 분모에 넣지 않는다. 원인을 확인한 뒤 승인된 새 조건만 진행한다. 현재 한계 이하의 실제 입력에서 문제가 생기면 해당 포장 조건을 초기값 적용 대상으로 소개하지 않고 파형·고정·임계값의 재검토 대상으로 남긴다. 전 회차에서 문제가 관측되지 않아도 해당 물·포장·시험대 조건의 관찰만 보고한다. 짐 보호율·실차 파손 감소·식품 온도 또는 열선 사용 승인으로 확대하지 않는다.

| 실행 ID·반복·조건 | 실제 치수·질량·여유 높이·뚜껑·캐리어 | 파형 파일/SHA·센서 오차 | 이동·누액·뚜껑 종점 | 중단·누락·원자료 |
|---|---|---|---|---|
| | | | | |

이 표는 빈 준비 서식이다. 실제 포장·장비·허용 시험 환경 확보 전에는 결과나 실시 횟수를 기입하지 않는다.
