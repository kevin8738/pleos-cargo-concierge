# v1.1.4 활성 세션과 SDK 연동 검증

2026-10-30 · Pleos release versionCode 7 · runtime-06 구현 검증 기준

**runtime-06은 도착 처리 중 멈춤 문제를 수정한 현재 후보입니다. 단위 시험 182건·빌드·서명과 정상 범위/경고 경계·실제 음향 대조·서비스 실패/복구·순정 내비 전환 중 수신·강제 종료/쉘 작업 제거를 확인했습니다. 위치 설정·재연결은 관측 범위를 구분했고, 제어 10조건·연속 동선 9조건도 통과했습니다.** runtime-04의 제어 실패와 runtime-05의 도착 처리 ANR은 원자료로 보존합니다. 이전 후보의 개별 통과를 새 APK의 결과로 합치지 않습니다.

## 현재 후보와 수정

APK는 **1.1.4-pleos / code 7**, 47,871,331바이트, SHA-256 `8971e207285f333c2c152f185e907ea1d38c01c04369473fc68c8f850f5e023c`입니다. 코어 158건·앱 24건, 총 **182건이 실패·오류·건너뜀 없이 통과**했습니다. Pleos release 빌드·서명 검증·Mock 컴파일 PASS, lint 오류 0건·경고 33건입니다. 공개 원자료는 동일 해시를 확인한 뒤 아래 색인에 연결합니다.

| 문제 | 수정·확인 범위 |
|---|---|

캐시 회귀는 동일 9건에서 수정 전 assertion 실패 8건, 수정 후 실패·오류·건너뜀 0건입니다. 종료 대기는 수정 전 회귀 1건 실패 후 새 3건·기존 시작 게이트 9건이 통과했습니다. 두 수정의 독립 코드 검토 필수 수정 사항은 0건이며 AVD 통과를 대신하지 않습니다. 기존 2초 차속 신선도·정차·P단·점유·공조 동기화 조건, 원값 소유권과 조건부 복원, G 초기값·안내 정책을 유지했습니다.

아래 색인의 경로는 제출용 공개 자료 배치 기준입니다. 파일 복사·DOCX 생성·패키지 체크섬 검수는 실행 시험의 통과와 별도로 확인합니다. [원자료 색인](검증자료/AVD_v1.1.4/README.md)에서 후보·실행·해시·정리 범위를 함께 확인합니다.

경계 시험은 음향을 모두 끄고 실제 수신 시각의 계산·배지·허용 요청을 대조했습니다. 최대 계산 차이는 약 2.78×10⁻¹⁷G, 보고 최대값은 0.1235446233G(화면 0.12G)이며 모의 입력·실주행 평가 불가를 유지합니다. 도착 직후 보고서 UI 응답·서비스 종료를 확인했고, 최종 Idle/P0는 이후 End/ack 정리에서 확인했습니다. 별도 음향 시험은 커피 선택 안내의 출력 대조이며 수신 PCM·패킷 메타데이터·WAV의 일치를 확인했습니다. 둘을 합쳐 실제 경고 발화·청취 품질을 검증했다고 쓰지 않습니다.

작업 제거는 확인된 VIP 단독 작업의 **쉘 제거**입니다. Recents 스와이프는 수행한 것으로 쓰지 않으며 `onTaskRemoved` 콜백은 직접 계측하지 않았습니다.

연속 영상의 최대 표시 4.49G는 Console/DDS 합성 재생의 원값입니다. 모의 입력·실주행 평가 불가·고G 원인 미확인 표시를 유지하며 정상 범위 경계 시험의 0.12354G와 목적을 구분합니다. 과거 3.69G·4.53G와의 차이를 정확도 개선이나 품목 보호 효과로 해석하지 않습니다.

## runtime-05 이력

APK SHA-256 `14709ea8c5b7c16f8d91592d27d3d408e65fd513fd8246aea004c71f1903fe03`의 `avd-02`는 제어 10/10·시험자 정리 PASS였고 원자료 63개 해시를 대조했습니다. 이후 `known-boundary-01`의 도착 처리에서 실제 앱 ANR이 발생해 **전체 실패·원래 정리 실패**로 보존했습니다. 별도 시험자 수동 복구에서 원래 음향 설정·진단 속성·Idle/P0·서비스/알림 없음·관측 차량 값 유지를 확인했습니다. 수동 복구로 원실패 판정을 바꾸지 않으며, 경고 계산 일부 일치도 전체 통과로 쓰지 않습니다.

## runtime-04 이력

이전 APK SHA-256은 `6d886a66a3170eda552dcbdb5b0951474134e94a3db78aad3f0923a30770947d`입니다. 당시 170건 시험·release·서명은 통과했지만 `avd-01`의 C3는 **18℃ 기대 / 22℃ 유지로 실패**했고 시험자 정리는 통과했습니다. 이 실패는 수정 전 이력으로 보존합니다.

- `runtime-avd-02`: 직접 비표시 상태를 확인한 뒤 20.129096초에서 tick 20개·최대 간격 1,004ms·TBT 7개. 경로 요청~복귀 전의 더 넓은 창은 ROUTE_DRIVE 1개·TBT 13개·FREE_DRIVE 1개입니다. 두 시간창을 혼합하지 않습니다.
- `fgs-failure-02`, `runtime-force-stop-01`: 시작 거절/승격 실패·복구와 강제 종료 뒤 1·8·18초 자동 미재개를 확인했습니다. 작업 제거는 해당 UI를 확인하지 못해 미실행으로 남겼습니다.
- 위치 4실행: 시스템 위치·구독 제어와 유휴 재연결 일부를 관측했습니다. GPS fix·캐시 실측 통과를 주장하지 않습니다.
- `known-answer-03`: 합성 차속 107개와 실제 수신 시각의 계산을 대조했습니다. 총 G 최대 계산 차이 약 6.94×10⁻¹⁸G, 보고 최대 0.06147058330461162G·화면 0.06G입니다. 모의 입력·실주행 평가 불가를 유지했습니다.

## 해석 범위

- 음향 **허용 요청과 실제 출력**은 별도입니다. 세션별 6회·음성 3회·공통 8초는 팀 정책(D)이며 명료도·내비 중첩·청취 부담의 측정값이 아닙니다.
- 합성 G 계산 일치는 입력→추정→표시 연결의 검증입니다. 실제 센서 오차·짐 보호 효과와 구분하며 한계 초기값의 D 등급은 유지합니다.
- 위치 구독·서비스 유형 관측은 GPS fix 정확도·권한 회수·모든 늦은 콜백의 검증이 아닙니다. JVM 캐시 회귀와 AVD 통합 결과를 구분합니다.
- 설정값 확인은 냉방·상자 온도·짐 보호 효과가 아닙니다. 차량 값과 앱 로그 관측을 차량 버스의 모든 쓰기 계측으로 확대하지 않습니다.
- 실제 사용자·실차 계측·품목 효과·재사용·구매/채널 결과는 0건입니다. [현장 키트](검증자료/현장검증_진행키트/README.md)의 CSV 8개는 데이터 0행의 실행 준비 자료입니다.

[v1.1.3 검증](검증_v1.1.3.md)의 161시험·3.69G·82.233889초 영상과 [v1.1.2 이력](검증자료/AVD_v1.1.2/README.md)의 4.53G는 당시 버전 결과로 보존합니다.
