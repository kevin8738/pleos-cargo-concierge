# VIP 조수석 — 시뮬레이터 구현

2021 IONIQ 5를 묘사한 차량으로 A 사람 기준과 B VIP 기준의 주행을 비교합니다. 차량·조수석 적재물·코칭 화면은 동일한 물리 계산에 반응합니다.

- 차량: 공식 사진과 제원을 참고해 제작한 차체·밝은 실내·20인치 휠을 사용합니다. 차체는 213,026면이며 Draco 압축을 적용했습니다.
- 실내: 흰 베젤 듀얼 디스플레이, 열린 바닥, Universal Island, 네 점 핸들을 표현했습니다. 조수석 적재물과 코칭 화면을 캐빈 시점에서 확인할 수 있습니다.
- 주행: 조향·바퀴 회전·제동등·계기판이 주행에 반응합니다. A와 B는 독립된 화면과 차량 상태로 같은 코스를 동시에 달립니다.
- 구성: 현재 차량 3종, VIP 분류별 적재물, Poly Haven 환경 모델·텍스처·야간 HDRI를 동봉합니다. Three.js와 Draco 디코더는 CDN에서 읽습니다.
- 검증: 차량 치수·바퀴 접지·조향·듀얼 화면·렌더링 분리와 전체 코스의 도착·비교 카드·단독 복귀를 검사합니다. 기준 수치는 [SPEC](SPEC.md)에 정리했습니다.

외형은 사진을 해석해 만든 설명용 재현이며 공식 CAD나 제조사 인증 모델이 아닙니다. 비교 수치는 실차 시험 결과가 아닙니다. 실행법·조작·에셋 출처는 [README](README.md)에 있습니다.
