# VIP 조수석 (Cargo Concierge) — 3D 주행 시뮬레이션 스펙 v1 (2026-10-28)

## 목적
현대자동차그룹 차량용 앱 공모전 출품작 「VIP 조수석」의 핵심 아이디어를 브라우저 3D로 보여 주는 시뮬레이션.
"사람 기준 0.40 G가 아니라 케이크 기준 0.15 G로 운전하면 케이크가 무사하다"를 같은 코스를 두 방식으로 달려 비교한다.
심사 PT·README·영상 캡처에 쓰므로 한 번에 이해되는 화면이 가장 중요하다. 게임이 아니라 설명 도구다.

## 장면
1. **코스**: 닫힌 루프 도로(아스팔트, 흰 차선, 노면 회색), 직선 + 3개 커브: R=30 m(급커브, 표지 "급커브"), R=60 m, R=120 m. 루프 1바퀴 ≈ 1.2~1.6 km. 밤 도시 분위기: 어두운 하늘, 가로등 몇 개, 멀리 건물 실루엣. 출발점에 "베이커리", 도착점(=출발점 직전)에 "주차장" 표지.
2. **차**: 로우폴리 세단(짙은 남색, 브랜드 로고·엠블럼·번호판 글자 없음). 바퀴 회전, 조향에 따라 앞바퀴 각도. 실내가 보이는 캐빈 카메라용으로 운전석·조수석·대시보드·센터 디스플레이(가로로 긴 패널)를 간단히 모델링.
3. **케이크 상자**: 조수석 시트 위, 흰 상자 + 금색 리본. 상자 안의 케이크는 보이지 않지만 "손상도"를 상자 위 작은 게이지와 HUD 숫자로 보여 준다. 한계 G를 넘으면 상자가 시트 위에서 살짝 밀리고(최대 8 cm) 기울어진다.

## 물리 (앱 `core/physics/GEstimator.kt`와 같은 식)
- 자전거 모델: 핸들 각 δ_sw(°) → 바퀴 각 δ = δ_sw / 15 (조향비 15:1), 축거 L = 2.9 m.
  횡가속도 a_lat = v² · tan(δ) / L (m/s²). 종가속도 a_lon = dv/dt (가속/제동). 총 G = sqrt(a_lat² + a_lon²) / 9.80665. 추정값은 EMA 0.5로 부드럽게.
- 차량 운동: 최대 가속 2.5 m/s², 일반 제동 4 m/s², 급제동 8 m/s²(=0.8 g), 핸들은 초당 최대 180° 회전, 손 놓으면 복원.
- 케이크 손상 모델(단순화, 솔직히 표기): 매 프레임 `over = max(0, totalG − limitG)`; 손상도 += over · dt · 400 (%). 100 %에서 "케이크 망가짐". 상자 밀림은 totalG > 0.30(시트-상자 마찰)일 때만.

## 앱 로직 미러 (이 규칙은 실제 앱 상태머신과 같다)
- VIP 분류별 한계 G: 케이크·디저트 0.15 / 뜨거운 음식 0.12 / 꽃·식물 0.20 / 신선식품 0.15 / 음료·국물 0.12 / 깨지기 쉬운 물건 0.12 / 전자기기·악기 0.25 / 반려동물 0.20 / 일반 짐 0.20. 기본 케이크.
- 배지: OK (< 80 % 한계) → NEAR (≥ 80 %: 진입 순간 짧은 효과음 1회 + 정적 배지, 화면은 바뀌지 않음) → OVER (> 100 %: 음성 코칭 문장 "핸들이 커져요. 조금만 부드럽게").
- 음성 코칭 상한: 한 바퀴(주행)당 최대 3회. 총 G ≥ 0.6(긴급 조작)이면 말하지 않음. 차속 < 15 km/h 선회(주차)에서는 말하지 않음.
- 사전 안내(F4): R=30 커브 100 m 전 "이번 코너는 25 km/h 이하로" (권장 속도 = sqrt(limitG · 9.80665 · R) · 3.6, 케이크 R30 → 24 km/h ≈ 25). 분류를 바꾸면 숫자도 바뀐다.
- 도착: 주차장에서 정지(기어 P)하면 "조수석 케이크 챙기세요" + 이번 주행 리포트(최대 G, 코칭 횟수, 손상도, 랩타임).
- 음성은 실제 소리 대신 디스플레이 패널의 말풍선 텍스트 + 작은 비프(WebAudio, NEAR 1회)로 표현. TTS API 사용 금지.

## 모드 (화면 상단 버튼)
- **A. 자동 주행 · 사람 기준**: 자동운전자가 커브를 약 0.40 G로 돈다(R30을 약 40 km/h). 직선 60 km/h, 제동은 4 m/s².
- **B. 자동 주행 · 케이크 기준**: 앱 코칭대로 R30을 ≤ 25 km/h, 커브 진입 전 부드럽게 감속(≤ 2 m/s²), 횡 G ≤ 0.15 유지. 직선은 같은 60 km/h.
- **C. 직접 운전**: ↑ 가속, ↓ 제동, ←/→ 핸들, Space 급제동, R 리셋. 터치 기기는 화면 버튼.
- 한 바퀴가 끝나면 **비교 카드**: A vs B — 최대 G, 손상도, 코칭 횟수, 랩타임(케이크 기준은 몇 초만 더 걸렸는지). A와 B를 순서대로 자동 실행하는 "비교 시작" 버튼.

## 카메라 (키 1/2/3)
1. 체이스 캠(기본): 차 뒤 위. 2. 캐빈 캠: 운전석 헤드레스트 뒤에서 조수석 상자와 센터 디스플레이를 보는 시점(상자가 밀리는 게 보여야 함). 3. 탑다운 지도: 코스 전체 + 차 위치 + 현재 G 벡터 화살표.

## HUD / 패널
- 좌상단: 모드·분류 선택(드롭다운 9종), 버튼. 좌하단: 속도 km/h, 핸들 °, 횡 G / 종 G / 총 G, 한계 G 바(80 % 눈금, 한계선), 최대 G, 코칭 n/3, 랩타임.
- 우하단 "센터 디스플레이" 2D 패널(앱 스타일: 배경 #0B0F14, 민트 #4FD1C5, 샴페인 #F2D18B, 둥근 모서리): 정적 배지(OK/NEAR/OVER), 말풍선(코칭·사전 안내·도착), 이벤트 로그 5줄.
- 하단 각주: "시뮬레이션 — 앱의 추정식(자전거 모델, 조향비 15:1, 축거 2.9 m)을 그대로 사용. 케이크 손상 모델은 한계 초과분 누적의 단순화."

## 품질 기준
- Chrome 최신에서 60 fps(일반 노트북), 1920×1080과 1280×720 모두 레이아웃 깨지지 않음. 콘솔 에러 0.
- 한국어 UI, 글자 겹침·잘림 없음. 밝은 대낮 느낌 금지(밤, 어두운 팔레트).
- 코드: 모듈 분리된 깔끔한 ES2020, 매직 넘버는 상수로, 함수마다 짧은 주석. 전체 1,500줄 이내.
