# v2.3 — 2021 IONIQ 5 최종 제출본

작성: 2026-10-29.

- 현대자동차의 2021년형 공식 사진과 제원을 기준으로 차체·밝은 실내·20인치 휠을 제작했습니다. 최종 구성은 차체 r9, 실내 r3, 휠 r2입니다.
- 차체에는 공식 전방 사진에서 생성한 TRELLIS.2 형상의 제한된 후드·지붕 곡률을 활용했습니다. 규칙 표면과 파트별 PBR 재질로 재구성했으며 원본 메시·UV 텍스처를 그대로 유지하지 않습니다. 차체 213,026면을 16비트 정밀도 Draco로 압축했습니다.
- 흰 베젤 듀얼 디스플레이, 열린 바닥, Universal Island, 네 점 핸들, 다이아몬드 격자 휠을 반영했습니다. 실내 문턱·발밑 측면·창 아래 트림을 연결하고 조수석 케이크와 코칭 화면의 가시성을 확인했습니다.
- 제출 패키지는 최종 차량 3종과 현재 VIP·환경 에셋을 포함합니다. 이전 시뮬레이션과 교체된 차량·실내 에셋은 현재 제출 트리에서 제외했습니다. 앱 규칙·물리 계산·카메라·분할 주행 코드는 유지했습니다.
- 최종 제출 패키지를 다시 열어 전체 코스 검사 36/36, 콘솔·페이지 오류 0을 확인했습니다. 기본 케이크 비교의 최대 G·손상도·랩타임·R30 속도·코칭·NEAR·OVER 7개 항목은 정리 전 결과와 정확히 일치했습니다. 유지한 에셋 68개의 체크섬과 최종 차량 3종의 원본 일치를 확인했습니다. 차량 외형은 중립 조명 7뷰와 시뮬레이터 진단 5뷰를 확인한 모델입니다.

외형은 사진을 해석해 만든 설명용 재현이며, 공식 CAD나 제조사 인증 모델이 아닙니다. 모서리·지붕·미러·휠은 근사 표현이고, 비교 수치는 실차 시험 결과가 아닙니다. 실행법·조작·에셋 출처는 [README](README.md), 현재 동작 규칙은 [SPEC](SPEC.md)에 있습니다.
